## [0.1.0](https://github.com/peymanpro/React-AI-Grounded-Responses/releases/tag/v0.1.0) — 2026-10-28

Initial public release.

### Added

- Provider-neutral claim-to-evidence ledger with structural validation for source references, ranges, quotes, and source-version or fingerprint changes.
- Streaming-aware response state and incremental parsing of numeric citation markers.
- Explicit conversion utilities for UTF-16 and Unicode code-point offsets.
- React primitives for rendering claims, displaying integrity status, and highlighting evidence in source text.
- Serializable snapshots suitable for passing data across a Next.js App Router Server/Client Component boundary.
- API, architecture, release, and security documentation, plus an App Router example and automated CI/release workflows.
